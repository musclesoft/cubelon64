Algorithm Notes:

  • Frame 0: Uses Tile 0 (blank) and Tile 1 (checkerboard)
  • Frame 1: Uses Tile 8 (cross) and Tile 9 (border)
  • Center tile = Tile0 XOR Tile1 (combined pattern)
  • Layout: 3x3 grid with T0, T1, Combined pattern
  • Each tile is 8x8 pixels (8 bytes of data)
