🎮 CUBELON Algorithm Comparison

Purpose: Compare all pattern generation algorithms side-by-side to choose the best one for C64 port
All algorithms animate in sync - Watch for differences in complexity and visual appeal

Master Controls

1. Simple 3x3

Basic pattern with XOR center tile. Minimal code, good for testing. Uses 2 base tiles per frame.
Complexity: ★☆☆☆☆
Visual Interest: ★★☆☆☆
Code Size: ~50 bytes

2. Full 8x8 Grid

Full grid with rotation and alternating patterns. Good variety. Position-based tile selection.
Complexity: ★★★☆☆
Visual Interest: ★★★★☆
Code Size: ~120 bytes

3. ZX Algorithm (Faithful) ⭐

RECOMMENDED: Faithful reproduction of ZX Spectrum algorithm. Symmetric patterns, quadrant-based layout, XOR combinations. Frame-based pattern set rotation for variety.
Complexity: ★★★★☆
Visual Interest: ★★★★★
Code Size: ~200 bytes
Matches ZX Spectrum aesthetic

4. ZX Algorithm (Simplified)

Simplified ZX algorithm for testing. Just checkerboard with rotation. Good for verifying rotation mechanics work correctly.
Complexity: ★★☆☆☆
Visual Interest: ★★★☆☆
Code Size: ~80 bytes

Algorithm Analysis:

  • Simple 3x3: Easiest to implement, minimal visual impact. Good starting point.
  • 8x8 Grid: More complex but still manageable. Good variety without too much code.
  • ZX Faithful (⭐): Best visual results. Matches original demo aesthetic. Worth the extra code.
  • ZX Simple: Test version. Verify rotation works before implementing full algorithm.

Recommendation for C64 Port:

Start with ZX Faithful (#3)
It provides the best balance of: - ✅ Visual complexity and interest - ✅ Matches original ZX Spectrum aesthetic - ✅ Reasonable code size (~200 bytes) - ✅ Uses proven algorithm from original demo

If code space is limited, fall back to 8x8 Grid (#2). If you need to test rotation first, use ZX Simple (#4).

Implementation Notes:

All algorithms use the same base operations: - rotateTileLeft(tile, n) - Circular byte rotation - xorTiles(tile1, tile2) - Pattern combination - Position-based selection - Grid layout

The difference is in the pattern selection logic and grid layout strategy.
